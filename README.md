# Biblioteca en Java

Proyecto desarrollado para practicar Programación Orientada a Objetos utilizando Java.

## Funcionalidades

- Agregar libros
- Buscar libros
- Editar libros
- Eliminar libros
- Listar libros

## Conceptos aplicados

- Clases y objetos
- Encapsulamiento
- ArrayList
- Separación de responsabilidades
- CRUD
- Validaciones básicas
